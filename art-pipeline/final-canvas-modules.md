# 终末画布核心：模块生产草案

状态：概念 APPROVED WITH NOTES；各模块无正式生成授权。尺寸、灰盒、节点朝向及碰撞接口待工程组确认；本文件不构成模型或集成验收。目标整套 40k–80k 三角形，按实测和运行时预算调整，不预先假定每个模块占额。

| 模块 ID | 范围 | 生产及控制约束 |
| --- | --- | --- |
| FC-01 | 主体外环与支撑 | 静态，分段或对称复用；与转动环留间隙。 |
| FC-02 | 中央画布 | 独立表面与材质槽，供工程切换视觉状态。 |
| FC-03 | 时间环与刻度 | 独立节点；旋转轴心居中，方向由工程确定。 |
| FC-04 | 前方球形能量核心 | 独立节点与发光材质；强度由运行时控制。 |
| FC-05 | 底座及台阶 | 静态分段；行走和碰撞使用工程组简化形状。 |
| FC-06 | 左右雕像 | 独立或镜像复用，避免不可逆合并到支撑。 |
| FC-07 | 布幔 | 独立装饰，是否需要动态由工程确认。 |
| FC-08 | 机械锁与钥匙插槽 | 锁的可动部分与插槽分别留节点、轴心和交互锚点；碰撞独立。 |
