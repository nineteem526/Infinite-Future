# Infinite Future

原创第一人称时空解谜游戏。当前为 M2 几何原型，尚非完整游戏。设计、架构、任务和验收规范见 `docs/`。参考图与原始 GLB 由用户保留在本目录，未纳入 Git。

## 原型启动

安装 Node.js 后在项目目录执行 `npm ci`、`npm run dev`，打开终端显示的本地地址。点击进入测试场；WASD 移动、鼠标观察、空格跳跃、E 切换时代、F 交互、R 重置。目标提示会引导你将未来的能源晶体带回过去，启动机关，随后进入未来通道。该版本是测试场，尚无完整剧情。生产构建使用 `npm run build` 和 `npm run preview`。
