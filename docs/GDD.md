# 游戏设计概要

《Infinite Future》是 Vernaux 城市中的原创第一人称时空解谜冒险。玩家作为时序修复师穿行 2026 与 2126，发现自己带回过去的技术参与维持终末画布；最终关闭时间封锁，回画廊在空白画布上留下第一笔颜色。主题：The future is not written.

依次为最后的画廊、失落的街区、时间工坊、终末画布、回到画廊。E 切换时代，F 交互；只能手持一件小物品，唯一 ID，过去的预设行动确定性改变未来。大物品不可携带。WASD、鼠标、空格为移动、观察、跳跃。

优先级：三分钟可操作演示，之后 8–10 分钟闭环，再考虑 15–20 分钟。Presentation Mode 使用检查点及故障恢复，展示开场、双时代切换、跳跃、物品与因果、真相及结局。M1 只是几何测试场，不代表正式关卡。
