# 时空切换参考：Titanfall 2

2026-11-08 研究记录。Respawn 设计师 Jake Keating 在采访中说明，《Titanfall 2》“Effect and Cause”将过去与现在建成上下叠放的两套场景；切换将玩家传送到另一套场景的对应位置。开发期间反复调整两套空间对齐，移动、跑墙与跳跃中也可切换。来源：[开发者采访](https://www.vice.com/en/article/a-behind-the-scenes-look-at-the-best-mission-in-titanfall-2/)、[Game Developer 报道](https://www.gamedeveloper.com/design/the-idea-for-i-titanfall-2-i-s-most-iconic-level-predates-the-series-itself)。

这些资料未说明玩家目标位置与墙体重叠时的具体算法；不能据此声称原作使用自动寻找安全点、挤出、或拒绝切换。

本项目结论：关卡设计应优先对齐两时代可行走空间、保持关键时空跳跃的精确坐标与动量；现有最多 1 米附近安全落点仅作为不安全重叠时的独立保护，不当作原作复刻。需要测试它是否造成错过平台、跨越本应阻挡的机关或影响谜题可读性；关卡内应尽可能通过布局避免频繁触发。禁止复制关卡和专有资产。

2026-11-08：对当前占位广场在 x/z 各 -25 至 25 米、1 米间隔、站立高度做抽样：2026→2126 共 2263 个来源可站点，其中 2192 个目标位置无遮挡、63 个可在 1 米内找到安全点、8 个未找到；2126→2026 分别为 2318、2192、75、51。该检查仅覆盖地面采样点及当前占位碰撞，不能代表全空间、空中路径或正式关卡。未来关键机关必须注册为受保护动态碰撞体；开启状态由世界状态驱动。
