# 验收规范

M1 必须在真实运行中验证：WASD、鼠标、跳跃与墙体碰撞；两时代无黑屏、无网络及重载切换；位置、视角、速度连续；空中切换；100 次连续切换；目标被墙占据时优先寻找附近安全位置，找不到时保持原状态并给反馈；快速按键不导致物理与画面不一致。记录设备、版本、具体步骤和结果，未测不得写通过。

M2/M3 增测唯一物品、手持切换、过去操作改变未来、重开、存档和检查点、完整通关。M5 在演示设备 1080p 实测帧率，以尽量稳定 60 FPS 为目标；测试展示检查点、故障恢复和备用录屏。

- 从新游戏出发，按玩家提示完成画廊开场、画框传送、街区双时代路径、时间工坊的晶体与因果机关、历史记录、终末画布核心和画廊落笔；记录实际步行路线、用时、卡点及结束条件。
- 主线测试须覆盖尚未获得折时仪时的限制、关键事件的顺序及重复交互、唯一物品、被阻挡切换、从任意章节重开；确保玩家不会跳过必要剧情或通过自动避障跨越关键闸门。
